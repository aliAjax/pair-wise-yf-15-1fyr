# 法医昆虫学样本保管链台账

面向法医昆虫学样本「现场 → 实验室」多段交接的保管链（Chain of Custody）登记工具，解决复核时看不出经手人、交接顺序无约束、温控/保存异常样本仍被签发的问题。

## 业务规则

### 四段顺序办理（前一段未完成，后一段不能办理）

1. **采集登记**：采样地点、现场环境温度、尸体暴露阶段、采样时间、原始保存方式、经办人/时间。
2. **接收登记**：接收时冷链温度、接收保存方式、接收岗位、经办人/时间。
3. **鉴定登记**：鉴定方法、置信度、鉴定意见拟稿、经办人/时间（锁定时仍可登记/更新拟稿）。
4. **结论签发**：授权签字人签发后保管链闭环；已签发样本不可再退回或更改。

### 退回

- 仅在签发前可办理，**必须填写退回原因**。
- 接收段 → 退回采集段；鉴定段（含已登记待签发）→ 退回接收段。
- 被退回段及其之后的登记（含复核/签发）标记作废并**完整保留在链中留痕**，回到上一段后可重新办理。

### 待复核锁定（自动判定）

接收登记时出现以下任一情况，样本即锁入「待复核」：

- 接收温度 **超过 8 ℃**；
- 接收保存方式 **与原始采集记录不一致**。

锁定期间：

- 鉴定结论**不能签发**（签发按钮禁用并提示原因）；
- 鉴定登记拟稿仍可填写；
- 复核人办理复核：**复核通过才放开**锁定允许签发；复核未通过则继续锁定。

### 列表与详情

- 列表支持按**案件**、**发育阶段**、状态筛选及编号/种类/地点搜索。
- 详情展示四段进度、锁定失效原因、样本原始信息，以及按时间排列的**交接记录时间轴**（含经办人、时间、退回原因、作废记录、复核结论与失效原因快照）。
- 全部数据保存在浏览器 `localStorage`，**重开页面记录仍保留**；经办人姓名会记忆复用。

## 技术栈

React 19 + Vite + TypeScript，无后端，数据持久化于 `localStorage`。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62003

构建：

```bash
npm run build
```

首次打开会写入 6 条演示样本，覆盖正常签发、温度超限、保存方式不符、复核未通过、复核通过放行、退回留痕等分支；可通过页面右上角「重置演示数据」恢复。

## 代码结构

- `src/types.ts`：保管链事件数据模型。
- `src/model.ts`：状态派生（当前环节、失效原因、锁定）、顺序/退回/复核规则与不可变动作、持久化。
- `src/seed.ts`：演示台账数据。
- `src/components/SampleDetail.tsx`：四段进度、锁定提示、交接时间轴、办理操作。
- `src/components/forms.tsx`：采集/接收/鉴定/签发/退回/复核/建档表单与校验。
- `src/components/ui.tsx`：按钮、徽标、表单字段、模态框等基础组件。
- `src/App.tsx`：列表筛选、状态管理与持久化编排。
