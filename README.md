# hxyfront-62003 法医昆虫学样本记录

源提示词编号：5

做一个法医昆虫学样本记录前端工具，用来记录采样地点、环境温度、尸体暴露阶段、昆虫种类、发育阶段、采样时间、保存方式和鉴定备注。页面需要有样本批次列表、发育阶段筛选、温度记录图、案件样本关联页和单个样本详情卡片。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62003

## 保管链台账（Chain of Custody）

- **三段交接**：样本按「采集 → 接收 → 鉴定登记」逐段登记经办人与时间；前一段未完成（或已退回）时，后一段不能办理。
- **退回**：必须填写退回原因，样本回到上一段，该段登记清空需重新办理，历史交接记录保留。
- **失效锁定**：接收/鉴定段实测温度超过 8℃，或保存方式与原始记录不一致时，样本锁入「待复核」，所有交接与鉴定结论签发均被禁止。
- **复核放开**：复核人处理失效记录，通过后样本解除锁定继续流转；不通过则保持锁定。
- **签发**：仅鉴定段、鉴定登记已完成且无未结失效记录时，鉴定结论方可签发。
- **筛选与详情**：列表按案件与发育阶段筛选（另有编号/种类/地点/备注搜索）；详情抽屉展示三段进度、失效原因与完整交接时间线。
- **持久化**：台账保存在浏览器 localStorage，重开页面记录仍保留；「重置演示」可恢复内置演示数据。
